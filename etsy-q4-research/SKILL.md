# Screenwriting Craft

## Purpose
Apply professional screenwriting craft — structure, dialogue, scenes, emotional beats — to any narrative writing, with a dedicated track for narrated YouTube stories (voiceover + visuals).

## Workflow
1. **Name the job:** full story build, beat-sheet outline, voiceover draft/rewrite, dialogue polish, or structure check.
2. **Load only the references the job needs:**
   - `references/structure-beats.md` — 3-act, Save the Cat beats, 8-sequence map, hero's journey.
   - `references/dialogue-scenes.md` — subtext, dialogue as action, scene construction, pacing.
   - `references/emotional-craft.md` — earning emotion honestly, plants/payoffs, arcs, endings.
   - `references/voiceover-application.md` — the full YouTube-narration adaptation (hooks, retention beats, voiceover rules, pre-write gates, exercises).
   - `references/format-reference.md` — only when writing actual screenplay pages (sluglines, action, dialogue blocks).
   - `references/sources.md` — the studied sites and how to keep learning from them.
3. **Build in beats first, prose second:** outline the beat sheet (timestamps for video work), confirm every beat turns, then write.
4. **Final pass:** run the Operating Rules as a checklist before delivering.

## Output Contract
- **Beat-sheet outlines:** beat name + timestamp + purpose + the turn (value shift).
- **Voiceover drafts:** narration text only (~120 wpm spoken), no camera directions; interior states, memory, dread/hope — never a description of what's already visible.
- **Structure checks:** each beat's function named; flag any beat that neither advances plot nor reveals character.

## Operating Rules
1. Never reproduce copyrighted material — distill craft only; illustrative snippets ≤ 2 lines.
2. **Subtext rule:** never narrate or state a feeling the audience can infer from observable behavior.
3. **Voiceover adds, never duplicates:** its jobs are emotional states and hints of what's coming — not what viewers already see.
4. **Enter late, leave early:** open mid-crisis, cut throat-clearing, deliver one ending — land it, then stop.
5. **Let the audience do the math:** give 2+2, never 4. Withhold the obvious conclusion; twists are revelations, not explanations.
6. Every beat/scene advances plot or reveals character (ideally both) **and turns** (hope→dread, trust→doubt).
7. **Plant and payoff:** nothing lands that wasn't set up; carry emotion in objects and rituals, not adjectives.
8. **One line of action per protagonist:** a visible want + an obstacle + emotional consequences of failure — or the story isn't ready.
9. Endings mirror or land: Opening Image/Final Image echo, or the 2-beat ending (setup line + ≤10-word quotable landing line).
10. Screenplay format (sluglines, caps, parentheticals) applies only to actual screenplay pages — narrated YouTube scripts are voiceover + visual cues, not screenplays.
