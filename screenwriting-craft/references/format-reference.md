# Screenplay Format Reference

Use **only** when writing actual screenplay pages. Narrated YouTube scripts use voiceover text + visual cues, not this format.

## The elements
- **Slugline (scene heading):** `INT./EXT.` + LOCATION + TIME OF DAY, ALL CAPS, one line, no fluff. Opens every scene; mid-scene slugs mark location/time shifts.
- **Action lines:** present tense, short paragraphs, one visual idea per paragraph. One long block is a classic amateur tell. Write what a camera could see — concrete, filmable.
- **Character names:** ALL CAPS above dialogue. In action, a name is capitalized **only at first introduction**, with one brief, castable, character-defining description — never a biography paragraph.
- **Dialogue:** set under the character cue in a narrow column; tight, speakable.
- **Parentheticals (wrylies):** sparingly, short, below the name — for V.O./O.S./cont'd or genuine emotional shifts. Never a substitute for good dialogue; never stage directions.
- **Transitions** (FADE IN:, CUT TO:) in caps at scene end — used rarely, mostly between sequences. Overuse is a rookie flag; most transitions are implied.
- **ALL CAPS** elsewhere is reserved for attention cues: key sounds, important props at first mention, effects cues — anything the reader must not miss.

## Conventions & common mistakes
- 12pt Courier; **~1 page ≈ 1 minute** of screen time.
- No camera directions in spec scripts (those belong to shooting drafts).
- Avoid: overlong action blocks, parentheticals that direct acting, unfilmable prose ("he contemplates his mortality" → show the Bible on the dresser, the funeral program placed on the table), "we see" crutches, on-the-nose dialogue.
