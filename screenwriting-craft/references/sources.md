# Sources Studied

All public pages; no logins. Craft distilled technique-level — no copyrighted passages reproduced in this skill.

## SimplyScripts — https://www.simplyscripts.com/
A free 27-year-old screenwriting library: searchable/alphabetical index of movie, TV, radio, anime scripts and transcripts, mostly linking out to hosts (The Daily Script, Screenplays for You, Drexel Screenplay Library, studio FYC PDFs) with metadata on writer, draft type/date, format. Also: weekly "Original Script Sunday" unproduced scripts, Oscar-nominated script pages, a screenwriter discussion board. **Best used as a finding aid** — use its index to locate a title, then read the HTML/text version on the linked host (reliably readable; PDFs inconsistently so).
- Full scripts studied via linked hosts: *Forrest Gump* (Eric Roth), *The Shawshank Redemption* (Frank Darabont), *Good Will Hunting* (Damon & Affleck). Craft mined: subtext, repetition-with-variation, object chains, bookends, earned sentiment, scene turns, misdirection.

## AwesomeFilm — https://www.awesomefilm.com/
**Important:** not a craft-education site. A veteran (c. 1998) contributor-fed **screenplay archive** — ~200 classic Hollywood scripts (PDF/TXT/HTML) plus outbound links to sibling archives. No formatting guides or structure articles on site. **Use as a reading room**: learn formatting by example, structure by analysis. Caveats: some entries are transcripts, not true screenplays; rights status unclear — link as "read produced scripts to learn," not a content source.
