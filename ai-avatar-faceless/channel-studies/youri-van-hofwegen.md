## 4. Editing mechanics

- **Burnt-in captions from frame 0:** bold white sans-serif, semi-transparent dark bar, 2 lines, centred lower third, phrase-level chunking (not karaoke).
- **Green-on-black keyword highlight boxes** for key terms.
- **Full-screen colour-coded prompt reveals:** green headings, yellow key phrases, slow pan/zoom across the text.
- **Screen recordings as zoomed crops** with cursor spotlight; hard cuts; speed-ramped UI clicks.
- **Very high b-roll density (~60% of runtime is generated footage): every claim is instantly shown.** Subtle push-ins on the avatar; ambient cinematic music bed under b-roll; whoosh SFX on every cut.

## 6. Avatar-mapping (what transfers to our pipeline)

Realistically automatable (script→voice→avatar→b-roll→edit→QC→package): burnt-in caption renderer, prompt-template library with colour-coded prompt reveals, one-call multi-scene generation with time-coded shot prompts, word-count↔duration validation, character-sheet builder from photo collage, lighting-direction prompt blocks, format presets (9:16/16:9), b-roll sequence generator, music/SFX beds, description/CTA/pinned-comment assembler, QC checks (silence detection, face consistency, word budget).

Needs a human: the hook and taste, the actual voice recording, personality/brand, choosing proof beats, the contrarian craft rules that make it feel expert rather than generated.

## 7. Craft rules encoded (→ skill §3f)

1. **Avatar-as-proof opener** — in tutorial content the avatar delivers the hook while already on screen in a cinematic scene; the presenter is the evidence, not a decoration.
2. **Three-failure agitation** — hooks agitate with three concrete, visible failure modes, never abstract pain.
3. **Anti-theory promise** — "the actual process start to finish" framing; promise procedure, not theory.
4. **Open-loop signposts** — when chapters are absent, every section opens with a verbal open loop that withholds the payoff.
5. **Contrarian craft rules** — opinionated rules beat rhetorical questions; "X does way more for you than Y" as the script voice.
6. **Concrete-number rule** — numbers instead of adjectives (word budgets, seconds, recording minutes).
7. **Reveal cadence** — one visible generated result every ~2–3 minutes; flag "telling without showing" stretches.
8. **Claim-is-shown density** — ~60% of runtime must be the thing being taught; never a claim without a simultaneous visual.
9. **Two-temperature lighting** — every realism prompt block names both light sources; prompt-block library of realism recipes (lighting, skin texture, reflections, breath in cold air).
10. **Voice-record-once checkpoint** — the human voice recording is the one irreplaceable step; the pipeline must block voice steps until a clean recording exists, then reuse the profile everywhere.
11. **One-call multi-shot generation** — compile one script into a single time-coded multi-shot generation prompt (~75 words/30 s budget).
12. **Format presets per output** — render queue applies aspect ratio and duration per target (9:16 short / 16:9 long-form).
13. **B-roll mode** — one image → 3 finished shots, ambient audio, no dialogue.
14. **Body-language direction presets** — talking-head avatars get named behaviours (hands move, shift weight, blink, glance away).
15. **Packaging assembler** — money link line 1, bonus link, SEO noun-stacked paragraph, free tool, email, disclosures; pinned comment duplicates the money links verbatim.
16. **Early conversion stack** — sponsor/bonus stack before the tutorial, not at the end; scarcity + price-parity framing.
17. **Disclosure as trust** — sponsorship and affiliate disclosures in every description; transparency is part of the proof.
18. **Meta-demo rule** — every tutorial must be produced with the same pipeline the video teaches.
